# omni-spec changelog

## 0.1.0 (2026-10-17)
First public release (pre-alpha). 25 modules implemented from published standards (Unicode UAX 9 / 14 / 29, JSON, XML, HTML tokenizer, DEFLATE, Brotli, ZIP, PNG, GIF, JPEG, WebP, OpenType, WOFF2, Office Open XML, WebM, Opus SILK / CELT parts), 113 tests, one module-index table in `README.md`.
Not shipped: five Unicode files above 1 MiB (`DATA.md`); the separate omni-posix crate. Known gaps, skipped checks and the open clone check: `STATUS.md`.
