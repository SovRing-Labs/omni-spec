# brotli — decoder (RFC 7932)

- **Spec:** RFC 7932 (Alakuijala & Szabadka, 2016), https://www.rfc-editor.org/rfc/rfc7932.txt — §3 prefix codes (3.2 canonical, 3.4 simple, 3.5 complex), §4 distances, §5 insert-and-copy, §6 block switching, §7 context modelling (Lut0/1/2, context maps, IMTF), §8 static dictionary and transforms, §9 format, §10 algorithm, Appendix A (dictionary) and B (transforms).
- **Code:** `src/brotli.rs` — `decompress`, `decompress_bounded` (default cap 256 MiB). Tables: `src/brotli_tables.rs` and `src/brotli_dict.bin`, generated by `tools/gen_brotli_tables.py` from `tests/data/rfc7932.txt`. Every extracted table is checked against the RFC's own values before writing: DICT 122,784 bytes CRC-32 0x5136cb04; transforms 648 bytes CRC-32 0x3d965f81; Lut0/1/2 CRC-32 0x8e91efb7 / 0xd01a32f4 / 0x0dd7a0d6.
- **Conformance:**
  - RFC §11.1 trivial-compressor streams (empty, "abc"): pass.
  - Black-box oracle (`tools/oracle_brotli.py`, Python `brotli` encoder/decoder run as a separate process) → `tests/data/brotli/*.br` + `tests/data/brotli-oracle.tsv`: **20 / 20 streams** decode to the original (length + FNV-1a 64). Set: RFC text (dictionary-rich) at qualities 0–11 and windows 10/16/22, seeded noise, runs, structured binary, a mixed 80 KiB stream, empty, one byte, repeats.
  - Corrupted and random inputs (1,500 bit-flip/truncation cases; 20,000 random short inputs): no panic.
- **Diagnostic note:** the stream that exposed a bug decoded a dictionary reference wrongly because dictionary distances were pushed to the ring; fixed (§4: dictionary references are not pushed).
- **Known gaps:**
  - WOFF2 container (RFC/W3C WOFF2 header and table directory) is not in this module; it belongs with the `sfnt` module (wave step 7), which will call `brotli::decompress`. No WOFF2 file is decoded here yet.
  - The oracle streams are produced by one encoder; coverage of every block-switch and context-map path is not instrumented (they are exercised by the q11 mixed stream but not measured).
  - Output is kept whole in memory (no ring-buffer streaming API); decoding is bit-serial (correct, not optimised).
  - Metadata meta-blocks are skipped; fill bits are checked for zero where the RFC requires it.
- **Patent screen:** Brotli (RFC 7932) — IETF RFC with no known patent claims. The reference implementation is MIT-licensed. No patent encumbrances declared in the RFC process.
