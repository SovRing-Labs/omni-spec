# sha256 — SHA-256 (FIPS PUB 180-4)

- **Spec:** FIPS PUB 180-4, Secure Hash Standard (SHS), NIST, August 2015, https://doi.org/10.6028/NIST.FIPS.180-4 — §4.1.2 functions, §4.2.2 constants, §5.1.1 padding, §5.3.3 initial hash value, §6.2 computation.
- **Code:** `src/sha256.rs` — `Sha256::{new, update, finish}`, `digest`, `hex`.
- **Conformance:** `cargo test --test sha256` — NIST example values ("abc", the 448-bit two-block message), empty string, one million "a"; incremental updates equal one-shot over 13 lengths × 5 split sizes (padding boundaries 55/56/57/63/64/65/119/120).
- **Why here:** omni-doc needs the vault's `weaver_hash` (SHA-256 of a note body) for incremental indexing and conflict detection without a third-party crate.
- **Known gaps:** none for SHA-256; SHA-224/384/512 not offered.
- **Patent note:** FIPS 180-4 is a U.S. federal standard; SHA-2 (U.S. patent 6,829,355, NSA) was released royalty-free and has expired. Release gate 3: recorded.
- **Provenance:** written from FIPS 180-4 only.
