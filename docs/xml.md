# xml — XML 1.0 pull tokenizer, tree and writer (W3C XML 1.0 5th ed. + Namespaces in XML 1.0 3rd ed.)

- **Spec:** Extensible Markup Language (XML) 1.0 (Fifth Edition), W3C Recommendation 26 November 2008, https://www.w3.org/TR/xml/ — §2.2 Char, §2.5 comments, §2.6 PIs, §2.7 CDATA, §2.8 prolog / DOCTYPE, §2.11 end-of-line handling, §3.1 tags, §3.3.3 attribute-value normalisation, §4.1 / §4.6 character and predefined entity references, §4.3.3 + Appendix F encoding detection. Namespaces in XML 1.0 (Third Edition), W3C Recommendation 8 December 2009, https://www.w3.org/TR/xml-names/ — §3 declaring, §5 scoping, §6 applying (default namespace applies to elements, not attributes).
- **Code:** `src/xml.rs` — `Reader` (pull events: Start / End / Text / CData / Comment / Pi / Doctype, each name a `QName { prefix, local, ns }` with its namespace URI resolved; `read_text`, `skip`), `parse` / `parse_bytes` → `Element` tree (`attr`, `attr_ns`, `child`, `children_named`, `descendants`, `text`), `decode` (UTF-8 / UTF-16 BOMs), `unescape`, `Writer` (`decl`, `start`, `attr`, `text`, `end`, `leaf`, `empty`, `raw`), `escape_text`, `escape_attr`, `is_xml_char`.
- **Conformance:** `cargo test --test xml` — 11 tests: declaration + DOCTYPE with an internal subset containing `]` inside a comment, comment, PI; predefined entities and decimal / hex / astral character references; CDATA + CRLF / CR normalisation; §3.3.3 attribute normalisation (literal tab/newline → space, references kept); default and prefixed namespaces, rebinding inside an element, `xml:` prefix; 13 malformed documents rejected (element type match, unclosed, end without start, two roots, text outside root, duplicate attribute, unquoted value, `<` in value, unterminated comment / CDATA / tag, undeclared entity, empty); BOM decoding; writer round trip with escaping (control characters dropped); 20,000 random / mutated inputs never panic.
- **Known gaps:** non-validating; DTD entity declarations are not expanded (an undeclared entity is an error — external entities are never fetched, so no XXE); names are not checked against the Name production; only UTF-8 / UTF-16 input.
- **Patent note:** W3C Recommendations are published under the W3C Royalty-Free Patent Policy. Release gate 3: recorded.
- **Provenance:** written from the two W3C Recommendations only.
