# zip — ZIP archives (PKWARE APPNOTE.TXT 6.3.10)

- **Spec:** PKWARE .ZIP File Format Specification, APPNOTE.TXT version 6.3.10 (2022-11-01), https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT — §4.3.7 local file header, §4.3.9 data descriptor, §4.3.12 central directory header, §4.3.14–4.3.16 ZIP64 end of central directory record / locator and end of central directory record, §4.4.4 general purpose bit flag (bit 0 encrypted, bit 3 data descriptor, bit 11 UTF-8 names), §4.4.6 MS-DOS date/time, §4.4.7 CRC-32, §4.5.3 ZIP64 extended information extra field, §4.6.9 Info-ZIP Unicode Path extra field, Appendix D (CP437 default name encoding). Deflate: RFC 1951 via `src/inflate.rs`. CRC-32 is the ISO 3309 / ITU-T V.42 polynomial already used by `src/png.rs` (`crc32`), reused, not duplicated.
- **Code:** `src/zip.rs` — `Archive::parse(&[u8])`, `entries()`, `find` / `find_ci`, `read` / `read_limited` (CRC + size checked; `MAX_ENTRY` 512 MiB zip-bomb guard), `raw`; `Writer` (`add_stored`, `add_dir`, `set_time`, `finish`), `crc32`, `dos_datetime`, `decode_cp437`.
- **Conformance:** `cargo test --test zip` — 13 tests. Fixtures in `tests/data/zip/` are written by Info-ZIP zip 3.0 (black box, `tools/make-zip-fixtures.sh`, our own content): stored, deflate (levels 9, binary + text), directories, forced ZIP64 (`-fz`), streamed to a pipe (data descriptor, bit 3), UTF-8 names (bit 11), archive comment. Our writer's output passes Info-ZIP `unzip -t` ("No errors detected"). CRC-32 check value `CBF43926` for "123456789". Robustness: 2,500 bit-flipped / truncated fixture variants and 5,000 random inputs return Ok or Err, never panic.
- **Write subset:** stored entries only (sizes + CRC in the local header, no data descriptor), deterministic timestamps (1980-01-01 unless `set_time`). This is what OPC packages need (ECMA-376 Part 2 Annex C allows stored items).
- **Known gaps:** no encryption (reported as `Encrypted`), no multi-disk (`MultiDisk`), compression methods other than 0 / 8 (`UnsupportedMethod`), no ZIP64 on write (deflate on write: `Writer::add_deflated`, docs/deflate.md), archives > 4 GiB on write refused (`Overflow`).
- **Patent note:** APPNOTE's format is openly documented by PKWARE; the stored and deflate methods and ZIP64 used here carry no known patent claims (Deflate: RFC 1951 was written to be patent-free; PKWARE's strong-encryption patents concern encryption, which is not implemented). Release gate 3: recorded.
- **Provenance:** written from APPNOTE.TXT text only; Info-ZIP tools were run as black boxes to produce fixtures and to test our output; their source was not read.
